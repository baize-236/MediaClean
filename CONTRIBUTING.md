# 贡献指南 / Contributing

欢迎使用中文或英文提交 Issue 和 Pull Request。先描述问题、复现步骤、预期行为、实际行为以及系统和依赖版本。只上传可以公开的合成或授权素材，不要附带个人任务数据库。

Issues and pull requests are welcome in Chinese or English. Include reproduction steps, expected/actual behavior and OS/dependency versions. Share only synthetic or authorized public fixtures, never personal task databases.

1. Fork 仓库并建立分支 / Fork and create a branch.
2. 修改代码；功能说明同步更新中英文文档 / Update both languages when changing documented behavior.
3. 运行 `npm test`；涉及 AI 时记录实际验证和限制 / Run tests and report AI checks and limitations where applicable.
4. 提交 PR，说明问题、解决方式和验证结果 / Explain the problem, change and validation in your PR.

不提交 `data/`、`.venv/`、模型、密钥或无权分发的素材。提交贡献表示你有权提供该内容，并接受项目 MIT 条款；第三方内容必须注明来源和许可。

Do not commit runtime data, environments, weights, secrets or media you cannot distribute. Contributions must be yours to provide under the project's MIT terms; identify third-party sources and licenses.
